# Architecture Decision Records

Use ADRs only for consequential decisions with meaningful alternatives and long-lived impact.

Suggested format:

```md
# ADR-NNN: Decision title

## Status
Accepted | Superseded | Deprecated

## Context
What forces/trade-offs made a decision necessary?

## Decision
What are we doing?

## Rationale
Why?

## Alternatives considered
What else was considered and why was it not chosen?

## Consequences
Positive, negative and follow-up implications.
```

Do not use ADRs as a dumping ground for normal implementation notes.
